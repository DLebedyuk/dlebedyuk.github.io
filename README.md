# Портфолио Дарьи Лебедюк

Личный сайт: https://dlebedyuk.github.io (русская версия) и https://dlebedyuk.github.io/en/ (английская).

Стек: Next.js 14 (App Router, статический экспорт), TypeScript, Tailwind CSS, Framer Motion, next-themes.
Деплой на GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`, срабатывает на push в `main`;
в настройках Pages источник должен быть «GitHub Actions»).

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # статический сайт в ./out
```

## Структура

- `app/(ru)/` — русская версия (`/`), `app/en/` — английская (`/en/`). Каждая со своим корневым layout,
  чтобы у страниц был правильный `<html lang>`.
- `lib/root-layout.tsx` — общий каркас: шрифты, тема, метаданные. `lib/config.ts` — адрес сайта.
- `components/` — секции страницы. Все получают готовый объект `c` с текстами на нужном языке.
- `content/` — весь текст сайта, компоненты его не хранят:
  - `profile.ts` — имя, роль, заголовок, текст под ним, «Обо мне», ключевые навыки, интересы,
    строка с городом и форматом работы;
  - `cv.ts` — опыт, образование, курсы и навыки из резюме (RU и EN рядом);
  - `case-studies.ts` — кейсы;
  - `en.ts` — английские переводы профиля, интересов и кейсов;
  - `ui.ts` — подписи интерфейса и заголовки секций на двух языках;
  - `index.ts` — собирает всё в объект для выбранного языка (`getContent(locale)`).
- `public/resume-ru.pdf`, `public/resume-en.pdf` — резюме для кнопок скачивания.

## Как править

- Текст: правится в `content/*`, русская и английская версии лежат рядом (в `cv.ts`, `ui.ts`) или в `en.ts`.
- Новый кейс: добавить объект в `content/case-studies.ts` (и, если нужен перевод, одноимённый `slug` в `content/en.ts`).
  Кейсы, в которых поле `context` пустое или начинается с `TODO`, на сайт не попадают, а поля с TODO скрываются.
- Заголовок секции: `eyebrow` — короткое имя секции, `title` — отдельная мысль, которая его не повторяет.
