# Портфолио — черновой каркас

Next.js 14 (App Router) + TypeScript + Tailwind + Framer Motion, статический экспорт под GitHub Pages
(репозиторий `dlebedyuk.github.io`). Сборка проверена локально (`npm run build` проходит, `next export`
генерирует `out/` с 4 страницами).

## Статус

Это **каркас с заглушками**, а не готовый сайт. Реальный опыт (кейсы, компании, метрики) нигде не
придуман — вместо этого в контенте расставлены `TODO`. Раздел Projects/GitHub — единственный, где данные
настоящие (собраны с github.com/DLebedyuk).

## Структура контента

Весь текст сайта лежит в `content/*.ts`, не в компонентах — чтобы редактировать было проще, без
трогания JSX:

- `content/profile.ts` — имя, роль, summary, `Things I Enjoy Solving`
- `content/case-studies.ts` — 9 кейсов из твоего ТЗ (Порт Транзит, ФГИС «Зерно», ЭТРН, Астрал,
  ГЛОНАСС, SOAP, автоматизация, релизы, управление командами) — **все поля TODO**
- `content/timeline.ts` — хронология (используется и в секции Experience, и как рельса Timeline —
  я их объединила в одну секцию `Experience`, см. "Что я сама решила" ниже)
- `content/projects.ts`, `content/skills.ts`, `content/architecture.ts`, `content/achievements.ts`

Карточки кейсов, у которых `draft: true`, показывают бейдж «Черновик — ждёт данных». Как только
заполнишь реальные факты — поставь `draft: false`, и бейдж пропадёт сам.

## Что я сама решила (без запроса) — можешь оспорить

- Объединила секции **Experience** и **Timeline** в одну (вертикальная рельса с периодами) — раздельно
  им пока не из чего быть, там одни и те же TODO. Если после заполнения данных станет ясно, что нужны
  разные форматы — разнесу обратно.
- Позиционирование в Hero/About ("Technical Project Manager... с глубоким техническим бэкграундом")
  взяла дословно из твоей формулировки задачи — не выдумка, но подтверди, что звучит правильно.
- `Things I Enjoy Solving` заполнила твоими же примерами из ТЗ (Complex integrations, Incident
  management и т.д.) — это черновик, а не факт, поправь под себя.
- Язык интерфейса — русский (по контексту домена: ФГИС, ЭТРН, ГЛОНАСС, Астрал). Если нужна английская
  версия — это отдельный заход (i18n), скажи, если понадобится.

## Как запустить локально

```bash
npm install

```

## Как собрать и задеплоить на GitHub Pages

В `.github/workflows/deploy.yml` уже настроен пайплайн: пуш в `main` → сборка → публикация в
GitHub Pages через `actions/deploy-pages`.

Разово в репозитории `dlebedyuk.github.io` на GitHub:
**Settings → Pages → Build and deployment → Source → "GitHub Actions"** (не "Deploy from a branch").

Дальше просто:

```bash
git init                      # если ещё не инициализирован
git remote add origin https://github.com/DLebedyuk/dlebedyuk.github.io.git
git add .
git commit -m "portfolio scaffold"
git push -u origin main
```

Actions сам соберёт и опубликует сайт на `https://dlebedyuk.github.io/`.

## Важно про папку `portfolio` (без `-site`)

Рядом в outputs есть папка `portfolio` (без суффикса `-site`) — это черновая, в неё я по ошибке поставила
зависимости (`npm install`) прямо в общей папке вывода, и там осталась куча файлов `node_modules`,
которые я не могу удалить программно. Используй эту папку — `portfolio-site` — она чистая, без
`node_modules`, и это единственная актуальная версия. Папку `portfolio` можешь спокойно удалить сама
через проводник/Finder на своей стороне.
